# Expritimentos: laboratorio de gráficos para un juego

Investigación de un flujo de trabajo para crear una interfaz pixel art y recursos de juego con ayuda de IA, Aseprite, aseprite-mcp y aseprite-live.

El juego se desarrollará entre dos personas. Buscamos diseños atractivos, consistentes y fáciles de animar y corregir. La prioridad no es reproducir las limitaciones de memoria de las consolas antiguas.

## Documentación compartida

- [AGENTS.md](AGENTS.md): instrucciones para las IA que trabajen con este repositorio.
- [Contexto y decisiones](docs/decisiones.md): objetivos confirmados, cuestiones pendientes y propuestas.
- [Dirección artística](docs/arte.md): criterios y método de trabajo propuestos para pixel art y animación.
- [Colaboración](docs/colaboracion.md): organización propuesta para las dos personas y sus asistentes.
- [Estado del laboratorio](docs/laboratorio.md): herramientas y experimentos locales recuperados.

## Estado actual

Esta primera versión publica la documentación de las conversaciones y del laboratorio. Todavía no contiene el código de un juego, las herramientas instaladas ni los gráficos de los experimentos.

Están pendientes el género, el motor, la perspectiva, las plataformas y la dirección artística final. Los tamaños y cantidades mencionados en las propuestas son ejemplos para experimentar, no especificaciones aprobadas.

Los chats de cada participante no se sincronizan automáticamente con el repositorio: hay que resumir los acuerdos, subirlos y actualizar la copia del otro participante.

## Para una IA que se incorpore

Lee primero [AGENTS.md](AGENTS.md). Para entender el objetivo consulta [docs/decisiones.md](docs/decisiones.md); antes de trabajar en gráficos consulta también [docs/arte.md](docs/arte.md).

Si tu herramienta no reconoce automáticamente AGENTS.md, pídele explícitamente que lo lea y siga sus referencias.
